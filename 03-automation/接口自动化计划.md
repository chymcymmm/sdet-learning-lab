# 接口自动化计划（P3）

## 目标

> 能写、能跑、能维护接口自动化测试，并测真实接口。

**脱 AI 验收**：不看 AI，用 `requests + pytest` 写一个接口测试并跑通。

## 两条落地线

| 线 | 内容 | 产物 |
|---|---|---|
| **1. Apifox 自动化** | 测试场景 → 接口步骤 → 断言 → 提取变量 → 运行 | 导出的测试场景 + 说明 |
| **2. Python 自动化** | api 封装 + pytest 用例 + 配置 + fixture | 可运行的 pytest 项目 |

## 学习清单

### 第一阶段：HTTP + 工具 ✅
- [x] HTTP 请求 4 部分 / 响应 2 部分
- [x] Apifox 发请求（Query / Header / Body）
- [x] HTTP 200 ≠ 业务成功（三层验证）

### 第二阶段：requests ✅
- [x] `requests.get` / `post`
- [x] 三件套：`params` / `json` / `headers`
- [x] `response.status_code` / `response.json()`

### 第三阶段：pytest（进行中）
- [x] 断言 assert
- [x] pytest 命名规则 / 自动发现
- [x] 参数化
- [x] 封装
- [x] Fixture 基础
- [ ] 见 `pytest学习地图.md` 第 9–27 条

### 第四阶段：工程化
- [ ] 分层（请求封装抽到单独文件）
- [ ] 配置管理（环境 / 域名 / 账号）
- [ ] 测试数据与代码分离
- [ ] 测试报告

### 第五阶段：真实项目
- [ ] 综合练习（一套完整接口测试）
- [ ] 测真实接口（脱敏）
- [ ] 业务场景：积分 / 退款 / 幂等 / 数据一致性
