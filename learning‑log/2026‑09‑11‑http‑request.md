# Day 01｜HTTP 请求结构学习总结

## 1. 学习目标
掌握 HTTP 请求五大结构：Method、Path、Query、Header、Body，
学会根据参数位置设计基础测试场景。

## 2. 核心知识点
- Path：URL ? 前面路径
- Query：URL ? 后面参数
- Header：请求头，不属于 URL
- Body：请求正文，多用于 POST

## 3. 参数测试思维（七层通用）
缺失 → 空值 → 格式错误 → 非法值 → 不存在 → 状态异常 → 权限异常

## 4. 常用参数测试场景
- Token：缺失、空、无效、过期
- platform：不传、空、非法值
- confirmTime：不传、空、格式错误
- 路径ID：正常、不存在、为空

## 5. 测试用例格式
测试条件、测试数据、预期结果
原则：**所有预期结果必须依据文档/业务，不瞎猜**

## 6. 今日收获
以前只会调通接口、看参数怎么传；
现在可以**区分参数位置 + 批量设计异常场景 + 有据可依写预期结果**。

## 7. 不足
需要继续熟练区分四种参数位置、加强异常场景设计、养成先对齐业务规则再写用例的习惯。
