## 二、核心知识

### D1 类型与字符串

```python
age = 25          # int
price = 3.14      # float
name = "张三"      # str（必须加引号）
is_vip = True     # bool

# 字符串：下标从 0 开始
s = "ABCDEFGH"
s[0:3]      # "ABC"（含头不含尾）
s[-2:]      # "GH"（后 2 位）
len(s)      # 长度
```

**运算符：**
```python
10 / 3      # 3.333...  普通除法
10 // 3     # 3         取整除法（砍掉小数）
10 % 3      # 1         取余
```

**比较：** `==` 等于、`!=` 不等于、`>` `<` `>=` `<=`

### D2 列表 list

```python
points = [100, 200, 300]
points[0]            # 100
points[-1]           # 300
points.append(400)   # 追加
points[0] = 999      # 修改
points.pop(1)        # 按下标删
points.remove(200)   # 按值删

for p in points:     # 遍历
    print(p)
```

### D3 字典 dict

```python
user = {"name": "张三", "point": 120}
user["name"]              # 取值
user["point"] = 200       # 修改（key 存在）
user["level"] = "VIP"     # 新增（key 不存在）
del user["name"]          # 删除

for k, v in user.items(): # 遍历
    print(k, v)
```

### D4 条件与循环

```python
# 多分支
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")

# while
i = 0
while i < 3:
    print(i)
    i += 1

# break / continue
for n in [1, 2, 3, 4, 5]:
    if n == 3:
        break       # 停止整个循环
    print(n)

for n in [1, 2, 3, 4, 5]:
    if n % 2 == 0:
        continue    # 跳过本次，继续下一轮
    print(n)
```

### D5 函数

```python
def add(a, b):
    return a + b

# return = 交货（外面能拿到）；print = 吆喝（只给人看）
def f1():
    print(5)      # 交出去的是 None

def f2():
    return 5      # 交出去的是 5

# 默认参数
def greet(name, greeting="你好"):
    return f"{greeting}, {name}"

# 多个返回值
def calc(a, b):
    return a + b, a - b
```

### D6 异常 + JSON

```python
# 异常
try:
    num = int("abc")
except ValueError:
    print("转换失败")

# 常见异常：ValueError / ZeroDivisionError / KeyError / TypeError

# JSON：接口返回的是 JSON 字符串，要转成 dict/list 才能用
import json

text = '{"code": 200, "data": {"point": 120}}'
data = json.loads(text)          # 字符串 → dict
print(data["data"]["point"])     # 120

s = json.dumps(data, ensure_ascii=False)   # dict → 字符串
```

## 三、两个核心模式

### 1. 遍历 + 条件 + 计数 / 累加

```python
# 计数
count = 0
for item in points:
    if item >= 100:
        count += 1
print(count)

# 累加
total = 0
for item in points:
    if item >= 100:
        total = total + item
print(total)
```

### 2. JSON 处理链

```
字符串（text）
   ↓ json.loads
列表（list）
   ↓ for 遍历
字典（dict）
   ↓ ["key"]
取值
```

**JSON 两种形状：**
- `{}` → 字典，用 `["key"]` 取值
- `[]` → 列表，用下标或遍历
- `[{...}, {...}]` → 列表套字典（接口最常见的结构）
